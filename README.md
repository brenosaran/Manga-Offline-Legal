# Mangá Offline — documentos legais

Documentos legais do aplicativo **Mangá Offline**, publicados via GitHub Pages:

- [Política de Privacidade (pt-BR)](https://brenosaran.github.io/Manga-Offline-Legal/privacy-policy.pt.html)
- [Privacy Policy (en)](https://brenosaran.github.io/Manga-Offline-Legal/privacy-policy.en.html)
- [Termos de Uso (pt-BR)](https://brenosaran.github.io/Manga-Offline-Legal/terms-of-use.pt.html)
- [Terms of Use (en)](https://brenosaran.github.io/Manga-Offline-Legal/terms-of-use.en.html)

Este repositório é público de propósito: a URL da política de privacidade é
exigida pela Google Play Console e precisa ser acessível sem autenticação,
enquanto o repositório do aplicativo permanece privado.

Cada documento existe em duas versões: `.md` (leitura aqui no GitHub) e `.html`
(versão publicada no GitHub Pages). Ao alterar um documento, atualize as duas.

Contato: <https://github.com/brenosaran/Manga-Offline-Legal/issues>
